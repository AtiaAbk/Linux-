## 📁 Terminal Basics

| Command | কাজ | বিস্তারিত |
|---|---|---|
| `pwd` | বর্তমান ডিরেক্টরির path দেখায় | [01-terminal-basics](../01-terminal-basics/README.md) |
| `whoami` | কোন user হিসেবে login করা আছো তা দেখায় | [01-terminal-basics](../01-terminal-basics/README.md) |
| `hostname` | মেশিনের নাম দেখায় | [01-terminal-basics](../01-terminal-basics/README.md) |
| `uname -a` | কার্নেল ও সিস্টেম info দেখায় | [01-terminal-basics](../01-terminal-basics/README.md) |
| `clear` | টার্মিনাল স্ক্রিন clear করে | [01-terminal-basics](../01-terminal-basics/README.md) |
| `history` | আগের চালানো কমান্ডগুলোর লিস্ট | [01-terminal-basics](../01-terminal-basics/README.md) |
| `man <command>` | কোনো কমান্ডের ম্যানুয়াল/ডকুমেন্টেশন দেখায় | [01-terminal-basics](../01-terminal-basics/README.md) |
| `date` | সিস্টেমের বর্তমান তারিখ/সময় | [01-terminal-basics](../01-terminal-basics/README.md) |
