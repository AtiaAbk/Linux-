## 📖 About This Project

Most "100 commands" lists are just a wall of text — a command, one sentence, next. This guide is different. It's built as an **interactive field guide** you can actually search, filter, click, and learn from, instead of scrolling past.

Every one of the 100 commands includes:

| | |
|---|---|
| 🎯 | **What it does** — plain-language purpose |
| ⌨️ | **Basic syntax** — the exact command you'd type |
| 🖥️ | **Typical output** — what you should expect to see |
| 💡 | **When to use it** — the real-world reason it matters |
| ⚠️ | **Safety / modern-Kali notes** — where relevant |

No fluff. No "just trust me." Just what you need to actually understand the tool.

> 🔒 **Ethics first.** Every example is designed to run against your own machine or an authorized lab. Nothing here is written as an operational attack instruction — this is a *learning* guide, not a toolkit for causing harm.

<br>

## ✨ Why Learners Like It

- 🔍 **Live search** — type `nmap`, `forensics`, or `wireless` and the whole guide filters instantly
- 🗂️ **5 skill categories** — Networking → Security Assessment → Forensics → Wireless/System → Recon & Utilities
- ⭐ **"Learn-first 20"** — a curated shortlist so total beginners know exactly where to start
- 💻 **Terminal-style cards** — click any command and it expands like a real terminal session
- 🧭 **Built-in learning path** — six structured levels from absolute basics to advanced forensics
- 📱 **Fully responsive** — works just as well on your phone during a commute as it does on a monitor

## 🚀 Getting Started

1. **Clone or download** this repo
2. Open **`kali_commands_guide.html`** in any browser — no install, no server, no dependencies
3. Search, filter, click, and learn
4. Spin up your own lab (a Kali VM + Metasploitable / OWASP Juice Shop is enough) and follow along safely

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
open kali_commands_guide.html   # or just double-click it
```

```
   OWN IT
     — or —
   HAVE EXPLICIT PERMISSION
     — or —
```
