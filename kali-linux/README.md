# 02 — Kali Linux

> Level: 🟢 Beginner

Kali Linux is a Debian-based distribution purpose-built for security testing, digital forensics, and reverse engineering. This module explains what Kali actually is, how it differs from a general-purpose distro, how to get it installed and running, and how its filesystem and defaults are organized before you ever touch a security tool.

2. [Kali vs Other Linux Distributions](02-kali-vs-other-distros.md)

4. [First Boot and the Kali Desktop](04-kali-desktop-and-first-boot.md)
5. [Kali's Directory Layout and Defaults](05-kali-directory-layout.md)

## What You'll Be Able to Do After This Module

- Explain what Kali is and who it's built for
- Choose the right installation method for your situation (VM, bare metal, WSL, cloud, live USB)
- Navigate a fresh Kali desktop and locate its tool menus
- Understand what makes Kali's defaults different from Debian's
