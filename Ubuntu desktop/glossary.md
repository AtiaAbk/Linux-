# 📖 Glossary

> Part of [Ubuntu Terminal Mastery](README.md)

| Term | Definition |
|---|---|
| **Shell** | The program that interprets your typed commands (e.g., Bash, Zsh). |
| **Kernel** | The core of the OS that manages hardware, memory, and processes. |
| **Distribution (distro)** | A packaged OS built on the Linux kernel (e.g., Ubuntu, Debian, Fedora). |
| **Daemon** | A background process/service (often named with a trailing `d`, e.g., `sshd`). |
| **PID** | Process ID — a unique number identifying a running process. |
| **PPID** | Parent Process ID — the PID of the process that spawned another. |
| **stdin/stdout/stderr** | Standard input / output / error streams for a process. |
| **Pipe (`\|`)** | Sends the output of one command as input to another. |
| **Redirection (`>`, `>>`, `<`)** | Sends output to/reads input from a file instead of the terminal. |
| **Environment variable** | A named value available to processes (e.g., `PATH`, `HOME`). |
| **Root** | The superuser account with unrestricted system access. |
| **sudo** | Runs a single command with elevated (root) privileges. |
| **Permissions (rwx)** | Read, write, execute rights on a file, set per owner/group/others. |
| **Symlink** | A shortcut file pointing to another file or directory. |
| **Mount point** | A directory where a filesystem/device is attached into the tree. |
| **systemd** | The init system managing services and boot on modern Ubuntu. |
| **Unit file** | A systemd config file defining how a service behaves. |
| **Package manager** | A tool for installing/removing/updating software (`apt`, `dpkg`, `snap`). |
| **Repository (apt)** | A remote source of installable packages. |
| **Cron** | A time-based job scheduler. |
| **Shebang (`#!`)** | The first line of a script specifying its interpreter (e.g., `#!/bin/bash`). |
| **Exit code** | A number (0–255) a program returns on completion; `0` = success. |
| **Regex** | Regular expression — a pattern language for matching text. |
| **SSH** | Secure Shell — encrypted remote login/administration protocol. |
| **Firewall** | A system that filters incoming/outgoing network traffic (`ufw`, `iptables`). |
| **Container** | A lightweight, isolated userspace instance sharing the host kernel (Docker/Podman). |

More terms are added as topic files are expanded — contributions welcome.
